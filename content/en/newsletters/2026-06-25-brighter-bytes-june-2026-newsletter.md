									<h3><span style="font-size:20px;"><span style="color:#003a70;">A Post-Quantum Future for Let’s Encrypt</span></span></h3>
									<span style="font-size:16px;">Let’s Encrypt is committed to a post-quantum-safe Web PKI. The path we’re planning to take is Merkle Tree Certificates (“MTCs”), a new approach that adds post-quantum authentication to the web without sacrificing the speed and reliability that have made TLS universal.<br>
									<br>
									This post is about these plans and why we believe MTCs are worth pursuing as a key to a post-quantum future.<br>
									<br>
									Continue reading the full blog post to <a href="https://outreach.abetterinternet.org/e/1011011/2026-06-03-pq-certs/4hq79/%%email_id%%/h/%%internal.tracker_url_hash%%">learn more</a>.&nbsp;</span><br>
									&nbsp;
									<h3><span style="font-size:20px;"><span style="color:#003a70;">Let's Encrypt Transitions to Generation Y Certificate Hierarchy</span></span></h3>
									<span style="font-size:16px;">Since our <a href="https://outreach.abetterinternet.org/e/1011011/2025-11-24-gen-y-hierarchy/4hq7d/%%email_id%%/h/%%internal.tracker_url_hash%%">November announcement</a>, all Let's Encrypt issuance has moved to the Gen Y hierarchy - a significant infrastructure milestone that keeps our Certificate Authority current with evolving browser and root program requirements. The one remaining exception, the allow-listed tlsclient profile, is on track to be retired in July, completing the transition.<br>
									<br>
									Staying ahead of these requirements is core to how Let's Encrypt maintains the trust the internet depends on.</span><br>
									&nbsp;
									<h3><span style="font-size:20px;"><span style="color:#003a70;">CAA Coming Your Way!&nbsp;</span></span></h3>
									<span style="font-size:16px;">In May, the CA/Browser Forum, which defines the rules for publicly trusted Certificate Authorities, voted to require the use of Certificate Authority Authorization (CAA) in 2027. CAA has been available at Let's Encrypt for several years so you can get ahead of this change and adopt CAA now.<br>
									<br>
									Read more about the benefits of CAA in <a href="https://outreach.abetterinternet.org/e/1011011/2023-09-07-caa23/4hq7h/%%email_id%%/h/%%internal.tracker_url_hash%%">this blog post</a>.</span><br>

									<h3><span style="font-size:20px;"><span style="color:#003a70;">Zlib-rs in Firefox!&nbsp;</span></span></h3>
									<span style="font-size:16px;">As part of Prossimo’s goal to move key pieces of software to memory safety, we worked with Tweede golf in 2023 to rewrite zlib in a memory safe language. zlib is a data compression library that has been in production for over 30 years and has wide adoption; it also has a long history of memory safety bugs. Zlib-rs is written in a memory safe language and has been steadily improving since Trifecta Tech Foundation (the nonprofit arm of Tweede golf) took over its maintenance. Recently, Mozilla adopted zlib-rs in Firefox, which will provide better security for everyone using Firefox. Thanks to the Trifecta Tech and Firefox teams for advancing memory safety!&nbsp;<br>
									<br>
									Read more about Firefox’s adoption in this <a href="https://outreach.abetterinternet.org/e/1011011/blog-zlib-rs-in-firefox-/4hq7l/%%email_id%%/h/%%internal.tracker_url_hash%%">recent blog post</a> from one of the Tweede golf developers.&nbsp;</span><br>

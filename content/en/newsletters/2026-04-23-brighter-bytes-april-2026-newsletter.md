									<h3><span style="font-size:20px;"><span style="color:#003a70;">The difficulty of making sure your website is broken.&nbsp;</span></span></h3>
									<span style="font-size:16px;">Most tools exist to keep certificates valid. But as a Certificate Authority, Let's Encrypt has to maintain test sites with certificates that are expired or revoked so that browser developers, security researchers, and TLS library authors can test whether their software correctly handles those failure cases. If no one maintains these, the safety nets go untested. Our engineers built a custom Go program to solve it, and as with most things at ISRG, we've open-sourced it so anyone can use it.<br>
									<br>
									If you want to see it in action you can read the blog post, try the test sites and browse the code. And here’s one of the <a href="https://outreach.abetterinternet.org/e/1011011/-txt/4bf1t/%%email_id%%/h/%%internal.tracker_url_hash%%">plain text only sites</a> with a little Easter egg.<br>

									<h3><span style="font-size:20px;"><span style="color:#003a70;">A resolute win for memory safety.</span></span></h3>
									<span style="font-size:16px;">Prossimo's investment in sudo-rs, a memory-safe reimplementation of one of Linux's most critical security tools, is paying off at scale. Ubuntu 26.04 LTS (Resolute Raccoon) ships sudo-rs by default and will provide five years of standard security updates, protecting millions of users, enterprises, and critical infrastructure deployments for years to come. <a href="https://outreach.abetterinternet.org/e/1011011/2026-04-23/4bf2t/%%email_id%%/h/%%internal.tracker_url_hash%%">The Trifecta Tech Foundation</a> maintains sudo-rs and we’d like to thank them for their work!<br>

<h3><span style="font-size:20px;"><span style="color:#003a70;">"Rust Makes Coding Fun Again" - Memory Safety in the Linux Kernel</span></span></h3>
<span style="font-size:16px;">In a recent interview, Greg Kroah-Hartman, a stable kernel maintainer, commented on the process of bringing in more memory-safe code. One of the benefits is reduced volume of CVEs caused by common, and easy to make, memory safety errors in code written in C.&nbsp;<br>
<br>
Read the full article <a href="https://outreach.abetterinternet.org/e/1011011/oah-hartman-linux-kernel-rust-/4mqn9/%%email_id%%/h/%%internal.tracker_url_hash%%">here</a>. Check out Prossimo’s efforts to improve memory safety in important software <a href="https://outreach.abetterinternet.org/e/1011011/2026-08-20/4mqnd/%%email_id%%/h/%%internal.tracker_url_hash%%">here</a>.&nbsp;</span><br>
&nbsp;
<h3><span style="font-size:20px;"><span style="color:#003a70;">A Memory-Safe SSH Server</span></span></h3>
<span style="font-size:16px;">Longtime Prossimo collaborator Dirkjan Ochtman has announced OxiSH, a new SSH server written in Rust. This is great news to us since SSH servers serve a critical function and the most widely-used ones are written in C and have a long history of memory safety issues. OxiSH is still early in its development, but it’s an exciting example of memory-safe alternatives being built for another foundational piece of Internet infrastructure.&nbsp;<br>
<br>
Read the full post <a href="https://outreach.abetterinternet.org/e/1011011/26-08-13-announcing-oxish-html/4mqm9/%%email_id%%/h/%%internal.tracker_url_hash%%">here</a>.&nbsp;</span><br>
